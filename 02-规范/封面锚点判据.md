# 封面锚点判据

> 内化自 **ponyo-cover-anchor-system**（<https://github.com/ponyodong2026/ponyo-cover-anchor-system>），裁剪为可执行判据，不整包引入、不产生运行时依赖。
> 用途：节点 ⑤（封面生产）出提示词时选模板、写锚点；确认点 1（★1 视觉母版确认）用 §④ 的诊断表过审。

## ① 双变量模型定义

封面强弱由两个变量共同决定：**信息密度 × 视觉锚点**。**信息密度**指在小红书信息流缩略图尺寸下，画面的核心利益点是否一眼看清（不是元素多寡，而是「利益点」的可读性）；**视觉锚点**指画面中让眼睛率先停留的核心焦点——通常是一个人物表情、一个大数字，或一块强对比色块。合格封面 = 利益点在缩略图下即可读（密度适中不堆砌） + 有且仅有一个明确锚点。两者缺一，封面在信息流里就「划过去了」。

## ② 6 模板

### 大字报型
- **适用内容类型**：干货教程、观点结论、强主张。
- **锚点是什么**：占画面主体的超大标题字（即锚点本身）。
- **提示词要点**：① 利益点浓缩成 ≤16 字的一句话主标题、字号压满；② 背景纯色或极简，禁止与文字抢焦点；③ 用一个 accent 色块或关键词变色制造视觉停留点。

### 人物情绪型
- **适用内容类型**：情感共鸣、经历叙事、人设向。
- **锚点是什么**：人物面部表情（喜/惊/无奈等，情绪即锚点）。
- **提示词要点**：① 人物半身或面部特写、表情明确指向单一情绪；② 文字辅助不压脸，留出情绪呼吸空间；③ 环境虚化，避免背景元素分散注意力。

### 数字冲击型
- **适用内容类型**：数据结论、盘点、量化承诺（「7 天」「3 步」「省 2000」）。
- **锚点是什么**：一个超大数字（数字即锚点）。
- **提示词要点**：① 核心数字放到最大、其余文字退居次级；② 数字用 accent 色与背景强对比；③ 数字后紧跟单位/结果词，让数字「有意义」。

### 对比型
- **适用内容类型**：测评、前后对比、选择建议。
- **锚点是什么**：左右/上下分割的强反差（反差即锚点）。
- **提示词要点**：① 画面二分，两侧一坏一好、色调冷暖分明；② 每侧一句话结论，不堆细节；③ 用 ✓/✗ 或红绿色引导「该选哪个」。

### 清单型
- **适用内容类型**：干货教程、步骤、盘点合集。
- **锚点是什么**：编号列表的规整结构（数字序列即锚点）。
- **提示词要点**：① 标题点明「N 个/N 步」预期；② 条目 ≤5、编号醒目、每条一行不换行；③ 留白规整，制造「一看就能收藏」的清爽感。

### 场景实拍型
- **适用内容类型**：生活方式、好物、探店、氛围向。
- **锚点是什么**：真实场景中的主体物/场景焦点（实物即锚点）。
- **提示词要点**：① 主体物居中或三分点、光线自然；② 文字做轻标注不喧宾夺主；③ 保留生活质感（避免过度精修的「广告感」）。

## ③ 选型映射表（内容类型 → 模板 → 出图方式）

**出图方式=产线二选一**：文字主导的 4 型（大字报/数字冲击/清单/对比）**首选产线甲 HTML→PNG 封面模板**（文字锚点 100% 可控、中文不糊、零生图依赖）；依赖真实图像或需浑然一体成品的 2 型（人物情绪/场景实拍）首选**产线乙 ponyo AI 成品封面**（image-gen-mcp 直出含字成品→`normalize-cover.mjs` 规范化 3:4）。**任意内容类型均可选产线乙**，由封面导演按素材与风格判断。

| 内容类型 | 首选模板 | 首选产线 | 备选 |
|---|---|---|---|
| 干货教程 | 大字报型 | 甲 HTML `templates/card-statement.html`（headline_size=120） | 乙 AI 成品 |
| 情感共鸣 | 人物情绪型 | **乙 ponyo AI 成品** | 甲 大字报（HTML） |
| 测评 / 对比 | 对比型 | 甲 HTML `templates/cover-compare.html` | 乙 AI 成品 |
| 数据结论 | 数字冲击型 | 甲 HTML `templates/cover-number.html` | 乙 AI 成品 |
| 盘点 / 步骤 | 清单型 | 甲 HTML `templates/cover-list.html` | 乙 AI 成品 |
| 生活方式 | 场景实拍型 | **乙 ponyo AI 成品** | 甲 大字报（HTML） |

> 走 HTML 封面（产线甲）时，若渲染 FAIL（溢出）或用户要求换风，按 §③ 备选列换另一个 HTML 封面模板或改走产线乙；走产线乙时若 2 轮仍不达标（中文乱码/构图差），降级到与内容最贴近的 HTML 封面模板（首选大字报型 card-statement）。封面模板变量表见 §⑤。

## ④ 过 / 不过诊断表（基础 ①-⑤ + 产线乙加 ⑥，确认点 1 验收表）

①-⑤ 逐字采用规格 §6.2；⑥ 为产线乙 AI 成品专属条件项。**任一项不过即封面不通过**，退回节点 ④ 或 ⑤。

| # | 诊断项 | 过 / 不过 | 怎么测 |
|---|---|---|---|
| ① | 缩略图尺寸下利益点可读 | | 把封面缩到 25% 看，利益点仍一眼可读则过 |
| ② | 有且仅有一个视觉锚点 | | 眯眼/离屏 2 米看，第一个抓住视线的焦点唯一则过；两个及以上争夺 → 不过 |
| ③ | 封面文字与标题互补不重复 | | 并排封面文字与 3 个标题候选，封面文字若原样复述某标题 → 不过（应补充信息而非重复） |
| ④ | 对比度足够 | | 转灰度看，文字/锚点与背景仍清晰可分则过；灰度下糊成一片 → 不过 |
| ⑤ | 信息密度适中（3 秒内可解析） | | 让未看过的人 3 秒内复述封面在讲什么，说得出则过；元素过多解析不出 → 不过 |
| ⑥ | 中文文字全部正确（**仅产线乙 AI 成品**） | | 逐字比对封面中文与 storyboard 封面文案：有乱码/错字/多余英文/水印/杜撰 logo → 不过，重生成或降级产线甲 |

## ⑤ 封面 HTML 模板变量表

4 个文字主导型封面模板（`02-规范/templates/`），均 1080×1440、内嵌 CSS、`{{变量}}` 占位、可变文本含 `word-break`、配色取自 [`视觉风格库.md`](视觉风格库.md)（`accent_color` 须 6 位 hex）。实例化后交 `node 04-工具/render.mjs <运行目录>` 渲染，溢出即 FAIL（缩内容不缩字号）。

| 模板 | 对应 ponyo 型 | 变量 |
|---|---|---|
| `card-statement.html` | 大字报型 | `bg_color` `accent_color` `kicker`(人群钩子) `headline`(≤16字, `<em>` 可局部变色) `headline_size`(封面=120) `sub` `page_no`(封面留空) |
| `cover-number.html` | 数字冲击型 | `bg_color` `accent_color` `kicker` `number`(1-3位，锚点) `unit`(单位/结果词) `headline`(数字的意义) |
| `cover-list.html` | 清单型 | `bg_color` `accent_color` `kicker` `title`(点明"N个/N步"，`<em>` 可变色) `item1`…`item4`(≤4条，不足删多余 `.item` 整块) |
| `cover-compare.html` | 对比型 | `bg_color` `accent_color` `kicker` `title` `left_head`/`left_point`(坏/前，✗) `right_head`/`right_point`(好/后，✓；good 栏拼 `{{accent_color}}1A` 透明底) |

人物情绪型 / 场景实拍型无 HTML 模板，走产线乙 ponyo AI 成品封面（提示词按 §② 要点 + `cover-anchor-system` skill 写，含准确中文文案；gpt-image-2 实测中文渲染可靠，确认点 1 §④⑥ 人审兜底）。
