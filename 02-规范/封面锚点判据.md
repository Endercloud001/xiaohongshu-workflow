# 封面锚点判据

> 内化自 **ponyo-cover-anchor-system**（<https://github.com/ponyodong2026/ponyo-cover-anchor-system>），裁剪为可执行判据，不整包引入、不产生运行时依赖。
> 用途：节点 ⑤（封面生产）出提示词时选模板、写锚点；确认点 1（★1 视觉母版确认）用 §④ 的 5 项诊断表过审。

## ① 双变量模型定义

封面强弱由两个变量共同决定：**信息密度 × 视觉锚点**。**信息密度**指在小红书信息流缩略图尺寸下，画面的核心利益点是否一眼看清（不是元素多寡，而是「利益点」的可读性）；**视觉锚点**指画面中让眼睛率先停留的核心焦点——通常是一个人物表情、一个大数字，或一块强对比色块。合格封面 = 利益点在缩略图下即可读（密度适中不堆砌） + 有且仅有一个明确锚点。两者缺一，封面在信息流里就「划过去了」。

## ② 6 模板

### 大字报型
- **适用内容类型**：干货教程、观点结论、强主张。
- **锚点是什么**：占画面主体的超大标题字（即锚点本身）。
- **提示词要点**：① 利益点浓缩成 ≤16 字的一句话主标题、字号压满；② 背景纯色或极简，禁止与文字抢焦点；③ 用一个 accent 色块或关键词变色制造视觉停留点。

### 人物情绪型
- **适用内容类型**：情感共鸣、经历叙事、人设向。
- **锚点是什么**：人物面部表情（喜/惊/无奈等，情绪即锚点）。
- **提示词要点**：① 人物半身或面部特写、表情明确指向单一情绪；② 文字辅助不压脸，留出情绪呼吸空间；③ 环境虚化，避免背景元素分散注意力。

### 数字冲击型
- **适用内容类型**：数据结论、盘点、量化承诺（「7 天」「3 步」「省 2000」）。
- **锚点是什么**：一个超大数字（数字即锚点）。
- **提示词要点**：① 核心数字放到最大、其余文字退居次级；② 数字用 accent 色与背景强对比；③ 数字后紧跟单位/结果词，让数字「有意义」。

### 对比型
- **适用内容类型**：测评、前后对比、选择建议。
- **锚点是什么**：左右/上下分割的强反差（反差即锚点）。
- **提示词要点**：① 画面二分，两侧一坏一好、色调冷暖分明；② 每侧一句话结论，不堆细节；③ 用 ✓/✗ 或红绿色引导「该选哪个」。

### 清单型
- **适用内容类型**：干货教程、步骤、盘点合集。
- **锚点是什么**：编号列表的规整结构（数字序列即锚点）。
- **提示词要点**：① 标题点明「N 个/N 步」预期；② 条目 ≤5、编号醒目、每条一行不换行；③ 留白规整，制造「一看就能收藏」的清爽感。

### 场景实拍型
- **适用内容类型**：生活方式、好物、探店、氛围向。
- **锚点是什么**：真实场景中的主体物/场景焦点（实物即锚点）。
- **提示词要点**：① 主体物居中或三分点、光线自然；② 文字做轻标注不喧宾夺主；③ 保留生活质感（避免过度精修的「广告感」）。

## ③ 选型映射表（内容类型 → 模板）

| 内容类型 | 首选模板 | 备选 |
|---|---|---|
| 干货教程 | 大字报型 | 清单型 |
| 情感共鸣 | 人物情绪型 | 大字报型 |
| 测评 / 对比 | 对比型 | 数字冲击型 |
| 数据结论 | 数字冲击型 | 大字报型 |
| 生活方式 | 场景实拍型 | 人物情绪型 |

> 无合适 AI 生图或中文渲染不可靠时，大字报型可降级走 HTML→PNG（复用 [`templates/card-statement.html`](templates/card-statement.html)，见 [`内页版式库.md`](内页版式库.md) 与规格 §3 节点 ⑤ 失败处理）。

## ④ 5 项过 / 不过诊断表（确认点 1 验收表）

逐字采用规格 §6.2 五项。**任一项不过即封面不通过**，退回节点 ④ 或 ⑤。

| # | 诊断项 | 过 / 不过 | 怎么测 |
|---|---|---|---|
| ① | 缩略图尺寸下利益点可读 | | 把封面缩到 25% 看，利益点仍一眼可读则过 |
| ② | 有且仅有一个视觉锚点 | | 眯眼/离屏 2 米看，第一个抓住视线的焦点唯一则过；两个及以上争夺 → 不过 |
| ③ | 封面文字与标题互补不重复 | | 并排封面文字与 3 个标题候选，封面文字若原样复述某标题 → 不过（应补充信息而非重复） |
| ④ | 对比度足够 | | 转灰度看，文字/锚点与背景仍清晰可分则过；灰度下糊成一片 → 不过 |
| ⑤ | 信息密度适中（3 秒内可解析） | | 让未看过的人 3 秒内复述封面在讲什么，说得出则过；元素过多解析不出 → 不过 |
