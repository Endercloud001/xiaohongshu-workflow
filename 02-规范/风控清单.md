# 风控清单

> 本文件是 [`04-工具/verify.mjs`](../04-工具/verify.mjs) 的**默认词表源**：脚本用正则抓取**本文件第一个 json 代码块**的 `banned` 数组做风控扫描（标题+正文+标签+引导语零命中才过）。
> 因此 §① 的 json 代码块必须保持为全文**第一个** json 块，格式恒为 `{"banned":[...]}`。切勿在它之前出现别的 json 代码块。

## ① 禁词词表（机器可读，verify.mjs 直接消费）

分类：**引流类**（微信/联系方式/私域导流）、**绝对化用语**、**医疗/金融断言**。可在此基础上增补，但至少包含以下词：

```json
{"banned":["微信","V.","VX","私信我","加我","公众号","QQ","二维码","绝对","最有效","第一名","根治","治愈","保证瘦","稳赚","躺赚"]}
```

- 引流类：`微信`、`V.`、`VX`、`私信我`、`加我`、`公众号`、`QQ`、`二维码`
- 绝对化：`绝对`、`最有效`、`第一名`
- 医疗断言：`根治`、`治愈`、`保证瘦`
- 金融断言：`稳赚`、`躺赚`

> 扫描为**子串匹配**（`fullText.includes(w)`）：新增词时注意勿与正常表达撞词导致误伤，宁可词表精准也不为过审删合理词。

## ② 敏感话题清单

以下话题只谈**个人体验、不下结论**，避免被判为专业建议/承诺：

| 话题 | 风险 | 规避方式 |
|---|---|---|
| 医疗诊断建议 | 无资质行医、误导用药 | 只谈个人体验不下结论（「我自己是这么做的」而非「你应该……能治好」） |
| 金融投资收益承诺 | 荐股/收益担保违规 | 只谈个人体验不下结论（不承诺收益、不喊单、不给具体标的） |
| 政治时事 | 平台高压线 | 只谈个人体验不下结论（不评论、不站队、不引战） |

## ③ 行为红线

| 红线 | 判据 | 出处 |
|---|---|---|
| 不自动互动 | Agent 不调用评论/点赞/收藏/关注类 MCP 工具；评论区首条引导语由用户手动发布 | 规格 §0 非目标 / §6.5 / §8.1 |
| 发布频率 | ≤ 2 篇 / 天 且相邻间隔 ≥ 4 小时 | 规格 §6.1（见 [`平台硬约束.md`](平台硬约束.md)） |
| 不搬运 | 不直接搬运他人图文/视频；对标只提炼结构不复制内容 | 规格 §11 风控 / §3 节点 ② |
