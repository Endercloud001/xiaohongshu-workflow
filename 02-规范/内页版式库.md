# 内页版式库

> 版式思路参考 **guizang-social-card-skill**（<https://github.com/op7418/guizang-social-card-skill>），裁剪为可执行索引，不整包引入、不产生运行时依赖。
> 本文件是 [`templates/`](templates/) 下 5 个**内页**卡片模板（`card-*.html`）的**索引 + 变量表**（模板本体在 templates/，本文件不复制 HTML）。变量表与模板文件**逐字一致**；改模板时同步改此表。
> templates/ 下另有 3 个**封面**模板（`cover-number.html` / `cover-list.html` / `cover-compare.html`），服务节点⑤封面生产，其变量表登记在 [`封面锚点判据.md`](封面锚点判据.md) §⑤，不在本文件。
> 画布固定 1080×1440，`devicePixelRatio=2` 渲染（[`04-工具/render.mjs`](../04-工具/render.mjs) 输出 2160×2880），配色变量取自 [`视觉风格库.md`](视觉风格库.md)。
>
> **（2026-07-04 更新）内页现为 AI 优先**：节点⑥内页**默认走产线乙 visual-director AI 成品内页**（`.claude/skills/xhs-visual-director/`，见 [`../03-skills/prompts/内页生成器.md`](../03-skills/prompts/内页生成器.md)）；本文件登记的 5 个 `card-*` 模板为**产线甲兜底**（确定性、中文锐利），用于密集精确清单/对比页与产线乙降级页。
> 内化风格系统来源：**xhs-visual-director-skill**（<https://github.com/ziguishian/xhs-visual-director-skill>，MIT）——仅供节点⑥消费知识，不整包替换本卡片库。

## 通用约定

- **公共变量**（每个模板都有）：`{{bg_color}}`、`{{accent_color}}`、`{{kicker}}`（顶部小标签/人群钩子）、`{{page_no}}`（右下角页码）。
- `accent_color` 必须是 **6 位 hex**（如 `#E64A2E`）——card-compare 会拼 8 位透明度后缀。
- **防溢出总则**：模板高度固定、`overflow:hidden`，超量文字会被静默裁掉。**条目不足时删除多余占位行，绝不追加行**；单条过长时精简文字，不靠缩字号救。render.mjs 检测 `scrollHeight > viewport` 会报溢出（节点 ⑥ 失败）。

## 模板索引

### card-statement.html — 观点大字卡
- **适用职能**：钩子 / 金句 / 干货点（单一强观点）。**兼任封面降级路线的大字报型封面**。
- **变量表**：

  | 变量 | 说明 |
  |---|---|
  | `bg_color` | 背景色 |
  | `accent_color` | 强调色（kicker、bar、headline 内 `<em>` 变色） |
  | `kicker` | 顶部小标签；封面用法作**人群钩子** |
  | `headline` | 主标题（`<em>关键词</em>` 可局部变 accent 色） |
  | `headline_size` | 标题字号（数值，不含 px）；**内页用法 `88`；封面用法 `120`** |
  | `sub` | 副标题/一句话补充 |
  | `page_no` | 页码 |

- **条目上限 / 防溢出**：单卡单观点，`headline` + `sub` 各一段；`sub` 不宜超 2 行。
- **封面 vs 内页**：内页 `headline_size=88`；**封面用法 `headline_size=120` 且 `headline ≤16 字`、`kicker` 作人群钩子**（见 [`封面锚点判据.md`](封面锚点判据.md) 大字报型）。

### card-checklist.html — 清单步骤卡
- **适用职能**：干货点 / 总结（编号要点、步骤）。
- **变量表**：

  | 变量 | 说明 |
  |---|---|
  | `bg_color` / `accent_color` / `kicker` / `page_no` | 公共变量 |
  | `title` | 卡标题 |
  | `item1_title` … `item5_title` | 第 1–5 条标题（编号 1–5 已在模板内写死） |
  | `item1_desc` … `item5_desc` | 第 1–5 条描述 |

- **条目上限 / 防溢出**：**checklist ≤ 5 条**。不足 5 条时**删除多余 `<div class="item">…</div>` 整行**（连同其 title/desc），不要留空占位。

### card-compare.html — 对比表卡
- **适用职能**：干货点（前后/优劣对比、选择建议）。
- **变量表**：

  | 变量 | 说明 |
  |---|---|
  | `bg_color` / `accent_color` / `kicker` / `page_no` | 公共变量（`accent_color` 须 6 位 hex，用于 `{{accent_color}}18` 透明底） |
  | `title` | 卡标题 |
  | `left_head` | 左列（坏/前）表头 |
  | `left1` … `left4` | 左列 1–4 行（模板内 `✗` 前缀） |
  | `right_head` | 右列（好/后）表头 |
  | `right1` … `right4` | 右列 1–4 行（模板内 `✓` 前缀） |

- **条目上限 / 防溢出**：**左右各 ≤ 4 行**。不足时**删除多余 `<div class="row">…</div>`**，左右尽量对齐行数。

### card-quote.html — 金句引用卡
- **适用职能**：金句。
- **变量表**：

  | 变量 | 说明 |
  |---|---|
  | `bg_color` / `accent_color` / `kicker` / `page_no` | 公共变量 |
  | `quote` | 金句正文（大字，模板已带 `“` 引号符） |
  | `attribution` | 署名/出处（右对齐，可留空） |

- **条目上限 / 防溢出**：单句金句，`quote` 控制在 2–3 行内最佳；过长精简，不换模板。

### card-cta.html — 总结CTA卡
- **适用职能**：总结CTA（回顾要点 + 行动号召）。
- **变量表**：

  | 变量 | 说明 |
  |---|---|
  | `bg_color` / `accent_color` / `kicker` / `page_no` | 公共变量 |
  | `title` | 卡标题 |
  | `recap1` / `recap2` / `recap3` | 回顾要点（模板内 `·` 前缀） |
  | `cta_text` | 底部 CTA 色块文字（点赞/收藏/关注引导） |

- **条目上限 / 防溢出**：**recap ≤ 3 条**。不足时**删除多余 `<div class="recap">…</div>`**；`cta_text` 一句话，1–2 行。

## 职能 → 模板速查

| 分镜表职能 | 首选模板 |
|---|---|
| 钩子 | card-statement |
| 痛点共鸣 | card-statement（观点式）/ card-compare（痛点前后对比） |
| 干货点 | card-checklist / card-compare / card-statement |
| 金句 | card-quote |
| 总结CTA | card-cta |
