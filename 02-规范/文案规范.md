# 文案规范

> 可执行判据：产出的标题/正文/标签/引导语须过 [`平台硬约束.md`](平台硬约束.md) 与 [`风控清单.md`](风控清单.md)，并由 [`04-工具/verify.mjs`](../04-工具/verify.mjs) 在节点 ⑧ 硬校验。用途：节点 ⑦ 文案定稿。

## ① 标题公式库

每篇产标题时覆盖不同公式。四类各 2 例句（示例，实作按主题改写）：

### 数字型（量化预期，降低点击成本）
- 「7 天早睡实验，第 3 天就有感」
- 「租房党必囤的 5 件小家电」

### 悬念型（制造信息缺口，勾点击）
- 「原来我一直睡错了，难怪总困」
- 「这个习惯坚持一个月，同事都问我」

### 身份共鸣型（点名人群，戳「说的就是我」）
- 「熬夜党自救指南，打工人码住」
- 「敏感肌换季，我只留这 3 步」

### 反常识型（打破默认认知，制造张力）
- 「早睡不靠自律，靠这一个开关」
- 「护肤越简单，皮肤反而越好」

### 产出规则（对接确认点 2）
- **每篇出 3 个候选**，覆盖**不同公式**（不得 3 个同型）。
- **标注推荐项**（copy.md 的 json 块 `recommended` 字段记推荐候选下标，0 起）。
- 每个候选 **≤ 20 字**（`verify.mjs` 逐候选校验）。
- **最终由用户在确认点 2（★2 发布放行）从 3 候选中选定**——Agent 只推荐不替用户拍板。

## ② 正文三段结构

**首行钩子 → 价值展开 → 提问结尾**，字数配比建议约 **1 : 7 : 2**，**总 ≤ 1000 字**（`verify.mjs` 校验）。

| 段 | 职责 | 要点 |
|---|---|---|
| 首行钩子 | 第一屏留人 | 一句话戳痛点/抛结论/亮利益，别铺垫 |
| 价值展开 | 兑现标题承诺 | 分点/分步，干货落到「怎么做」，可对应内页卡片 |
| 提问结尾 | 引导评论互动 | 抛一个低门槛问题，自然过渡到评论区引导 |

## ③ 标签策略

**3–6 个**（`verify.mjs` 校验数量），结构建议：**1 大流量 + 2 垂直 + 1 长尾**（可在 3–6 区间内增补垂直/长尾）。

| 类型 | 作用 | 示例 |
|---|---|---|
| 大流量 | 蹭大盘曝光 | #好物分享 #自律 |
| 垂直 | 精准圈层 | #睡眠 #早睡打卡 |
| 长尾 | 低竞争精准词 | #熬夜党自救 |

## ④ 评论区首条引导模板（≥3 条）

发布后由用户手动贴到评论区，用于承接互动、加权算法。模板（按主题改写）：

1. 「你一般几点睡呀？评论区蹲一个作息～」
2. 「第 3 步很多人漏掉，有在做的扣个 1👀」
3. 「还想看哪类的？评论告诉我，下期安排」

> **加粗注明**：**评论区首条引导语由用户在发布后手动贴到评论区（发布后 1 小时内，配合算法加权）。工作流及 Agent 在任何情况下不得调用评论类 MCP 工具代发**——自动互动是本项目自定的风控红线（规格 §6.5 / §8.1）。`receipt.md` 附引导语文本并提醒用户手动发布。
