# 平台硬约束

> 本文件是**可执行判据**：每条约束都能回答「过 / 不过」。数值全部取自 [`00-总览/工作流规格说明.md`](../00-总览/工作流规格说明.md) §6.1 与 §9，**不得自创**。
> 校验方式列：`verify.mjs` = 由 [`04-工具/verify.mjs`](../04-工具/verify.mjs) 程序化执行；`人工` = 需人工确认，脚本不覆盖。

## 约束表

| 约束 | 值 | 出处 | 校验方式 | 违反后果 |
|---|---|---|---|---|
| 标题字数 | ≤ 20 字（3 个候选各自 ≤20） | 规格 §6.1 / §9 | `verify.mjs`（`[...t].length > 20`，逐候选） | 节点 ⑧ 拦截，退回节点 ⑦ 压缩重写 |
| 正文字数 | ≤ 1000 字 | 规格 §6.1 / §9 | `verify.mjs`（`[...body].length > 1000`） | 节点 ⑧ 拦截，退回节点 ⑦ 压缩重写 |
| 图片数量 | 2–9 张（含封面） | 规格 §6.1 / §9 | `verify.mjs`（`pngs.length < 2 \|\| > 9`） | 节点 ⑧ 拦截，退回节点 ④/⑥ 增删页 |
| 图片比例 | 3:4，即 1080×1440（2 倍图 2160×2880 比例不变） | 规格 §6.1 / §8.2 | `verify.mjs`（读 PNG IHDR，`\|w/h − 3/4\| ≤ 2%`） | 节点 ⑧ 拦截；回填图不过退回回填协议第 2 步 |
| 封面存在 | `images/cover.png` 必须存在 | 规格 §4.1 / §9 | `verify.mjs`（`pngs.includes('cover.png')`） | 节点 ⑧ 拦截，退回节点 ⑤ |
| 图片路径 | 本地纯英文命名（`^[a-z0-9._-]+$`）、文件存在 | 规格 §2 设计纪律 / §6.1 / §9 | `verify.mjs`（正则 + 目录读取） | xiaohongshu-mcp 发布失败；节点 ⑧ 提前拦截 |
| 风控词 | 扫描零命中（标题+正文+标签+引导语） | 规格 §6.6 / §9 | `verify.mjs`（词表源 [`风控清单.md`](风控清单.md) json 块） | 节点 ⑧ 拦截，退回节点 ⑦ 改词 |
| 标签数量 | 3–6 个 | 规格 §6.5 / §9 | `verify.mjs`（`nTags < 3 \|\| > 6`） | 节点 ⑧ 拦截，退回节点 ⑦ |
| 登录态 | 同账号**单**网页端登录（多端并发登录触发风控） | 规格 §8.1（check_login_status） | 人工（发布前 `check_login_status`；扫码登录唯一网页端会话） | 未登录 → 停止，提示扫码；多端 → 人工下线其他会话 |
| 发布频率 | ≤ 2 篇 / 天 | 规格 §6.1 / §11 风控 | 人工（对照 [`05-验收/已发档案.jsonl`](../05-验收/已发档案.jsonl) 当日条数） | 超频 → 暂停发布，改约次日档期 |
| 发布间隔 | 相邻两篇间隔 ≥ 4 小时 | 规格 §6.1 | 人工（对照 已发档案.jsonl 最近一条 `date`/`publish_slot`） | 间隔不足 → 顺延到满足 4h 的档期 |

## 说明

- **程序化 vs 人工的边界**：字数、图片数量/比例/命名、风控词、标签数量属确定性判据，由 `verify.mjs` 在节点 ⑧ 一次性执行；登录态与发布频率/间隔依赖账号侧实时状态与历史档案，脚本不覆盖，须人工核对。
- 频率/间隔的判据数据源是 `05-验收/已发档案.jsonl`（每次发布追加一行，含 `date` 与 `publish_slot`）。
- 本文件只列**硬约束**；封面质量、风格一致性等软判据见 [`封面锚点判据.md`](封面锚点判据.md) 与 [`视觉风格库.md`](视觉风格库.md)。
