# 账号档案

> 这是可换、可多份的账号配置，工作流节点①（档案加载）读取它确定本次创作边界。

```yaml
version: 1
mode: 探索                    # 探索 | 深耕
persona: 帮你省时省钱的成年人生活攻略员
audience: 独居/租房的年轻上班族 + 刚独立生活的新手 + 在校大学生
candidate_domains:            # 探索模式按数组顺序循环轮换
  - 生活技能干货              # 主：省时省钱的生活攻略、避坑、整理术
  - 家常菜快手菜              # 辅：低成本好上手的一人食/快手菜
  - 独居租房好物              # 连接线：租房场景的实用好物清单
candidate_styles:             # 均对应 02-规范/视觉风格库.md 的条目
  - 纪实生活感                # 成品图/场景图主风格
  - 温暖插画                  # 情绪/治愈封面与配图
  - 手绘涂鸦标注              # 教程要点圈画、清单标注
tone: 温暖、治愈、实用、清单感
image_strategy: >-
  封面优先 HTML 文字模板（干货清单类，见封面锚点判据 §③ 出图方式）；配图/成品图优先
  AI 生成（回填协议，按 ponyo 锚点 + 视觉风格库骨架出提示词），其次自有拍摄；网络图仅限
  可商用授权（CC0/无版权素材站/自有版权），禁直接搬运他人图（风控红线，见风控清单.md）。
```

规则：`mode: 探索` 时按 `candidate_domains` 数组顺序循环轮换（第 N 篇取第 `N mod 领域数` 项；用户指定主题明显属于某领域时以主题为准并记录实际 domain）；累计 9-12 篇后依已发档案手动收敛为 `mode: 深耕`（本版不自动收敛）。**首跑前置条件**：`candidate_domains` 与 `candidate_styles` 非空——已填写，满足首跑条件。
