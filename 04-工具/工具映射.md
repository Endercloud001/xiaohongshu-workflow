# 工具映射

> 工作流各节点用到的外部工具、本地脚本、生图通道与降级规则。

## 1. MCP 工具（xiaohongshu-mcp @ http://localhost:18060/mcp）

| 工作流节点 | MCP 工具 | 降级 |
|---|---|---|
| 前置检查 | `check_login_status` / `get_login_qrcode` | 未登录 → 停止，提示扫码 |
| ② 对标研究 | `search_feeds` → `get_feed_detail` | 失败 → 降级跳过，research.md 记「未对标」 |
| ⑨ 发布 | `publish_content`（支持定时） | 失败 → 先查主页确认未发出，再重试 1 次 → 停止保留产物 |
| ⑨ 发布防重检查 | 用户主页最新笔记查询（**实测时确认具体工具名**） | 查询失败 → 状态不明，不自动重试，停止问人 |

其余 MCP 工具（评论/点赞/收藏等）**本版不使用**（风控红线；评论区首条引导语由用户手动发布）。

## 2. 本地脚本（零/单依赖，确定性）

| 脚本 | 用途 | 用法 | 退出码 |
|---|---|---|---|
| `04-工具/render.mjs` | HTML→PNG 渲染（1080×1440→2160×2880），溢出检测 | `node 04-工具/render.mjs <运行目录>` | 0=全成功 / 1=有溢出FAIL / 2=用法或环境错误 |
| `04-工具/verify.mjs` | 发布前硬校验（标题/正文/标签/图片/风控词） | `node 04-工具/verify.mjs <运行目录> [词表md路径]` | 0=全过 / 1=校验不过 / 2=用法或文件缺失 |
| `04-工具/normalize-cover.mjs` | AI 封面原图 → 精确 1080×1440(2160×2880@2x) 3:4 | `node 04-工具/normalize-cover.mjs <运行目录>`（读 `assets/cover-src.png`，出 `images/cover.png`） | 0=成功 / 1=源图不可解码 / 2=用法或缺源图或浏览器错误 |

依赖：render.mjs 需 puppeteer（见项目根 package.json）；verify.mjs 零依赖。

## 3. 生图通道（产线乙 · 已接入 image-gen-mcp）

封面产线乙走 `mcp__image-gen-mcp__generate_image`（模型 `gpt-image-2-official`，经 apimart 中转、异步补丁；配置见该 MCP 项目 `.env`）。

流程：封面导演出 `prompts/cover-prompt.md` → `generate_image(size=auto, quality=high)` → 返回 `image_url`(file://) 拷到 `<运行目录>/assets/cover-src.png`（**不进 `images/`**，避开 verify 逐张 3:4 校验与图片计数）→ `node 04-工具/normalize-cover.mjs <运行目录>` 规范化到精确 3:4 `images/cover.png`。

**降级链**：generate_image 失败 / ponyo skill 缺失 / normalize FAIL / 确认点1 判中文乱码或构图差 → 重生成 → 仍不过 → 转产线甲 HTML 文字封面（render.mjs，已验证兜底）。

**说明**：`size=auto` 让上游读提示词 3:4 线索，但比例不保证，故 normalize 步骤为强制、确定性归一化，不赌 auto。
