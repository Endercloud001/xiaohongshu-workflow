# 工具映射

> 工作流各节点用到的外部工具、本地脚本、生图通道与降级规则。

## 1. MCP 工具（xiaohongshu-mcp @ http://localhost:18060/mcp）

| 工作流节点 | MCP 工具 | 降级 |
|---|---|---|
| 前置检查 | `check_login_status` / `get_login_qrcode` | 未登录 → 停止，提示扫码 |
| ② 对标研究 | `search_feeds` → `get_feed_detail` | 失败 → 降级跳过，research.md 记「未对标」 |
| ⑨ 发布 | `publish_content`（支持定时） | 失败 → 先查主页确认未发出，再重试 1 次 → 停止保留产物 |
| ⑨ 发布防重检查 | 用户主页最新笔记查询（**实测时确认具体工具名**） | 查询失败 → 状态不明，不自动重试，停止问人 |

其余 MCP 工具（评论/点赞/收藏等）**本版不使用**（风控红线；评论区首条引导语由用户手动发布）。

## 2. 本地脚本（零/单依赖，确定性）

| 脚本 | 用途 | 用法 | 退出码 |
|---|---|---|---|
| `04-工具/render.mjs` | HTML→PNG 渲染（1080×1440→2160×2880），溢出检测 | `node 04-工具/render.mjs <运行目录>` | 0=全成功 / 1=有溢出FAIL / 2=用法或环境错误 |
| `04-工具/verify.mjs` | 发布前硬校验（标题/正文/标签/图片/风控词） | `node 04-工具/verify.mjs <运行目录> [词表md路径]` | 0=全过 / 1=校验不过 / 2=用法或文件缺失 |

依赖：render.mjs 需 puppeteer（见项目根 package.json）；verify.mjs 零依赖。

## 3. 生图通道（半自动回填）

本版无自动生图 MCP。封面与 ai-image 内页走**回填协议**（见 [`../00-总览/工作流规格说明.md`](../00-总览/工作流规格说明.md) §5）：工作流出提示词 → 用户用任意生图工具生成 → 放回指定路径 → 工作流校验 3:4 后继续。

**升级路径**：未来接入生图 MCP 时，仅替换回填协议第 2-3 步为工具调用，提示词文件格式不变。封面在回填失败时可降级为 HTML→PNG（card-statement 模板）。
