# 小红书工作流 · 使用说明

> 日常使用速览。完整细则见 [`工作流规格说明.md`](工作流规格说明.md)，主控编排见 [`../03-skills/SKILL.md`](../03-skills/SKILL.md)。

## 怎么触发

- 新笔记：`/xhs <主题>`，或对 Agent 说「按小红书工作流创作 <主题>」
- 续跑：`继续 <run目录名>`
- 首次建议逐节点协作，这样更容易在 ★1 / ★2 处拍板

## 主流程

```text
① 档案加载 → ② 只读研究 → ③ Topic Gate → ④ 选题定角 → ⑤ 分镜规划
→ ⑥ Style Router → ⑦ 封面生产 → ★1 视觉母版确认 → ⑧ 内页生产
→ ⑨ Visual Gate → ⑩ 文案定稿 → ⑪ 组包终审 → ★2 发布包确认
→ ⑫ Publish Pack
```

## 你需要手动做的事

1. ★1 确认封面、分镜和母版方向
2. ★2 确认标题与图片顺序
3. 手动发布到小红书
4. 发布后把笔记链接发回，让工作流补录 `receipt.md`
5. 发布后 1 小时内手动贴评论区首条引导语

## 研究与视觉是怎么跑的

- 研究：OpenCLI 首选，redbook 可增强，xiaohongshu-mcp 只做兜底
- 封面：`cover-anchor-system` 首选，失败时按路由降级
- 内页：`xhs-visual-director` 首选；清单 / 对比 / 数据 / 密集中文页优先 `guizang-social-card-skill`
- 终极兜底：HTML 模板 + `render.mjs`

## 手动发布包里有什么

`manual-publish.md` 会包含：

- 推荐标题 + 备用标题
- 正文
- 标签
- 评论区首条引导语
- 推荐发布时间
- 发布前人工核对项
- 图片顺序清单

## 真发前置

- 若只做研究与成稿，不需要发布登录态
- 若 OpenCLI 不可用，研究兜底需要 xiaohongshu-mcp 登录态
- 不再通过工作流自动发布
