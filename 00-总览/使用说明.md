# 小红书工作流 · 使用说明

> 面向日常使用的速览。完整细则见 [`工作流规格说明.md`](工作流规格说明.md)，主控编排见 [`../03-skills/SKILL.md`](../03-skills/SKILL.md)。

## 怎么触发

- **新笔记**：`/xhs <主题>`，或对 Agent 说「按小红书工作流创作 <主题>」
- **续跑**（跨会话/中断后）：「继续 <run目录名>」（如 `继续 20260702-rent-traps`），Agent 读该 run 的 run.yaml，从最后一个完成节点之后接着跑，已批准的确认点不重复
- 也可以逐节点对着聊（每一步看产物、你拍板）——首次建议这样

## 主流程（你只在 2 处需要拍板）

```
① 档案加载 → ② 对标研究(搜小红书爆款) → ③ 选题定角 → ④ 分镜规划
→ ⑤ 封面(HTML优先) →〔★1 确认封面+分镜〕→ ⑥ 内页 → ⑦ 文案(3标题候选)
→ ⑧ 硬校验 →〔★2 选标题+说"发"〕→ ⑨ 发布 → 归档
```

- **★1 视觉母版确认**：Agent 给封面图 + 分镜表 + 封面 5 项诊断，你说「通过」或「改哪里」（最多 2 轮）
- **★2 发布放行**：Agent 给完整预览包 + 3 个标题候选，你选一个并决定 **发 / 定时 / 先存档**（approved_unpublished）
- **回填协议**：需要 AI 生图时（人物情绪型/场景实拍型封面、氛围配图），Agent 给提示词 → 你用任意生图工具出图、存回指定路径 → 回「图好了」→ Agent 校验 3:4 后继续

## 图片是怎么来的

- **封面**：文字主导型（大字报/数字冲击/清单/对比）走 **HTML→PNG**（中文锐利、零版权风险、零生图成本）；人物/实拍型走生图回填
- **内页**：5 个 HTML 卡片模板（观点大字/清单/对比/金句/CTA），程序渲染成 3:4 图
- **配图/成品图**：优先 AI 生成（回填），其次自有拍摄；**网络图仅限可商用授权，禁直接搬运**（风控红线）

## 账号现状（探索模式）

- 领域轮换：生活技能干货 → 家常菜快手菜 → 独居租房好物
- 锁定风格：纪实生活感 / 温暖插画 / 手绘涂鸦标注
- 人设：帮你省时省钱的成年人生活攻略员；语气：温暖、治愈、实用、清单感
- 攒够 9-12 篇后依 `05-验收/已发档案.jsonl` 数据收敛到 1 个领域，转「深耕模式」

## 每篇你要手动做的 2 件事

1. 发布后 1 小时内**手动贴评论区首条引导语**（Agent 会给话术；工作流不代发评论——风控红线）
2. cookies 过期时**扫码登录**：Agent 用 `mcporter call 'xiaohongshu-mcp.get_login_qrcode()' --save-images <dir>` 取二维码给你扫（二维码约 3 分钟有效）

## 真发前置

- 启动 `xiaohongshu-mcp-windows-amd64.exe`（端口 18060）
- 登录态有效（`check_login_status` = 已登录）
- 干跑（①→⑧，不发布）不需要登录，随时能跑

## 参考提示词（复制改用）

**最简版**：

```
/xhs 出租屋 200 块布置得温馨治愈
```

**带控制版**（一次交代偏好，减少来回）：

```
按小红书工作流创作一篇笔记，主题：一个人住怎么把每天伙食费压到 20 块。
探索模式当前轮到「家常菜快手菜」领域，用手绘涂鸦标注风格；封面走 HTML 数字冲击型
（大字突出省钱数额），内页 5-6 张信息卡，文案给我 3 个标题候选。
跑到 ★2 发布前停下等我确认，先不真发。对标研究照常先搜同题材爆款。
```

**续跑/改稿版**：

```
继续 20260702-rent-traps，把第 3 页"假精装"的说明改短一点，重渲染给我看
```
