## 对外可见的发布前检查

- 公开分支指向 `public/main`
- 根目录 `LICENSE` 和第三方说明已经分开
- README、目录结构和公开命令已对齐
- 任务 1—9 的状态在本文件中可直接查看

## 仍需人工完成的步骤

1. 在 GitHub 页面把仓库可见性从 private 切换为 public
2. 确认默认分支和 release 标签指向公开分支
3. 用未登录浏览器或匿名 clone 核对 README、LICENSE、第三方说明和目录结构
4. 创建首个公开 release，并补上发布说明
5. 公开后重新执行安装、配置、smoke、测试和 fixture verify
