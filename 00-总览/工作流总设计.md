# 工作流总设计（总览索引）

> 权威细则见 [`工作流规格说明.md`](工作流规格说明.md)。本文件只做入口索引和一图流。

## 一句话

这不是自动发帖机，而是一套只读研究、可插拔视觉生成、双闸门复核、人工发布的轻编辑部工作流。

## 主流程

```text
① 档案加载 → ② 只读研究 → ③ Topic Gate → ④ 选题定角 → ⑤ 分镜规划
→ ⑥ Style Router → ⑦ 封面生产 → ★1 视觉母版确认 → ⑧ 内页生产
→ ⑨ Visual Gate → ⑩ 文案定稿 → ⑪ 组包终审 → ★2 发布包确认
→ ⑫ Publish Pack（手动发布后补录）
```

## 自动化边界

- 双确认：★1 视觉母版确认、★2 发布包确认
- 研究只读：不做自动互动，不做自动发布
- 产物先落盘：任何失败不丢已有产物
- 降级不中断：研究、视觉都允许按规则降级
