# ponyo 封面生图融合 · 设计规格（v1）

> 2026-07-03 头脑风暴定稿。将 `image-gen-mcp`（gpt-image-2-official，走 apimart 中转、异步补丁）与 `cover-anchor-system`（ponyo 封面锚点 skill）融合进小红书成稿工作流的**封面节点⑤**，新增「AI 成品封面」产线。经用户批准，路径乙（ponyo 直出含字成品封面）为主推。

## 1. 背景与目标

- 现状：封面节点已有「半自动回填」抽象（[工具映射.md](../04-工具/工具映射.md) §3），并预留升级位「未来接入生图 MCP 仅替换回填第 2–3 步」。
- 目标：把 ponyo skill + image-gen-mcp 接成一条**自动化的 AI 成品封面产线**，与现有 HTML 文字封面产线并存，封面导演按内容二选一。
- 实测依据（本次会话）：
  - image-gen-mcp 已接入、异步补丁生效、真机可出图。
  - ponyo 方法论产出的封面**中文渲染 2/2 全对、锐利无乱码**（推翻了「AI 中文不可靠」的旧假设）。
  - 3:4 可达成：强提示词「3:4 1080×1440」+ `size=auto`，apimart 产出 ~1086×1448（比例 0.7500，过 verify ±2%）。
  - 样本：[06-产出/20260702-rent-traps/images/ponyo-gen-cover.png](../06-产出/20260702-rent-traps/images/ponyo-gen-cover.png)（1086×1448）。

## 2. 双封面产线模型

封面导演（节点⑤）按内容类型与账号风格**二选一**：

| 产线 | 触发 | 流程 | 特点 |
|---|---|---|---|
| **甲 · HTML 文字封面**（保留·兜底） | 文字主导型 / AI 成品失败降级 | 选 HTML 模板 → 填变量 → `render.mjs` → 3:4 PNG | 中文绝对锐利、零生图依赖、确定性 |
| **乙 · ponyo AI 成品封面**（新增·主推） | 需要图像化/浑然一体的成品封面 | ponyo 出成品提示词 → `generate_image` → 规范化 3:4 → `cover.png` | 视觉整体、含手绘装饰；中文靠人审把关 |

内页始终走 HTML 信息卡（**不变**）。

## 3. 3:4 达成配方（硬约束桥接）

平台铁律：封面 3:4（1080×1440），[verify.mjs](../04-工具/verify.mjs) 逐张卡比例 ±2%、图片数 2–9。AI 出图比例不确定（`size=auto` 多为 3:4，但不保证；显式 `1024x1536` 则为 2:3）。因此：

1. **提示词**强写：`3:4 vertical, 1080x1440` + 「关键文字/数字置于中央安全区，远离上下边缘」。
2. **调用**：`generate_image(size=auto, quality=high)`（`size=auto` 让 apimart 读提示词 3:4 线索）。
3. **确定性规范化（新增组件）**：生成后必做一步，产出精确 1080×1440 的 `cover.png`——
   - **实现方式（推荐，零新依赖）**：复用 puppeteer。把 AI 图作为 `background:cover` 塞进 1080×1440 空 HTML 框截图 → CSS `cover` 做确定性居中裁切 → 输出精确 1080×1440（DSF 可选，与 render.mjs 一致产 2160×2880）。
   - 不引入 sharp 等新依赖。
   - 组件名暂定 `04-工具/normalize-cover.mjs`（或并入 render.mjs 的一个子命令），实现细节留给实现计划。
4. **原始 AI 图**存 `{run_dir}/assets/`（**不进 `images/`**，避免被 verify 当第 N 张图且非 3:4 而误拒）；规范化后的 `cover.png` 才进 `images/`。

## 4. 封面导演节点重写（[03-skills/prompts/封面导演.md](../03-skills/prompts/封面导演.md)）

产线乙流程：
1. 按 ponyo 模板选择矩阵（[cover-anchor-system/SKILL.md](../.claude/skills/cover-anchor-system/SKILL.md)）+ 账号 `candidate_styles` 选型，写选型理由。
2. **可选**调用 `cover-anchor-system` skill 产出成品提示词（含准确中文文案、锚点位置、配色 HEX、字重层级、装饰）。skill 不可用时退回 [视觉风格库.md](../02-规范/视觉风格库.md) 骨架自撰提示词。
3. `generate_image(prompt, size=auto, quality=high)` → 原图存 `assets/`。
4. 规范化 3:4 → `images/cover.png`。
5. `run.yaml` tool 记 `ponyo-ai-cover`；降级时记 `html-cover` 并入 degradations。

产线甲流程与现状一致（不改）。

## 5. 降级链（reliability 核心）

```
产线乙 ponyo AI 成品
  └─(确认点1 判：中文乱码 / 构图差 / 有水印杜撰)
      └─ 重生成（换提示词 / 多打 2-3 张选一）
          └─ 仍不过 → 退回 产线甲 HTML 文字封面（已验证兜底）
```

AI 生图/skill 缺失/网络失败，均可直接走产线甲兜底。

## 6. 人审关卡（确认点 1 · 视觉母版确认，强化）

AI 非确定性，确认点 1 是中文与合规的最后防线。逐张核：
1. **中文正确性**：所有文字正确、无乱码、无多余英文。
2. **锚点与缩略图可读**：80px 缩略图仍能看清主标题与锚点。
3. **合规**：无水印、无杜撰 logo/二维码/数据、无 `@` handle。
不过 → 重生成或降级产线甲。

## 9. 新增组件

- `04-工具/normalize-cover.mjs`（或 render.mjs 子命令）：AI 图 → 精确 1080×1440 3:4，puppeteer 实现，零新依赖。退出码契约对齐 render.mjs（0/1/2）。

## 10. 验收标准

- **脚本化**：ponyo 出 1 张原图 → normalize → `verify.mjs` 全绿（cover.png 存在且 3:4、assets/ 不入 images 计数、图片数仍 2–9）。
- **人审**：确认点 1 清单加「中文正确性」项。
- **干跑**：新起一篇用产线乙封面端到端跑通（研究→定角→分镜→ponyo封面→内页→文案→双确认→归档），确认点 1 目检中文与构图。
- **降级活体**：模拟 AI 失败 → 自动退回产线甲 HTML 封面并过 verify。

## 11. 不做（YAGNI）

- 不接内页 AI 配图（本轮仅封面）。
- 不做 HTML 背景层叠字（路径乙不叠 HTML 文字）。
- 不做多风格批量候选（先单张，不满意重生成）。
- 不改 image-gen-mcp 的 apimart 异步补丁之外的东西（补丁维护见记忆 [[image-gen-mcp-apimart-async-patch]]）。

## 12. 已知约束 / 风险

- **AI 中文可靠性**：实测 2/2 通过，但样本量小；靠确认点 1 人审 + 产线甲兜底控制风险。
- **`size=auto` 比例不保证**：故必做 §3 规范化，不赌 auto。
- **apimart 异步补丁是本地 fork**：`image-gen-mcp` `git pull` 后须重打（见记忆）。
- **中转 Key 明文风险**：建议轮换（见记忆）。
