# 全新环境验收

> 目标：让第一次接触公开仓库的人，在项目目录外用一个全新的临时目录完成匿名 clone、安装、硬校验和公开前审计。
> 约束：不要复制账号档案、cookies、`.redbook`、本地缓存、额外的私有 Skill 副本或任何个人绝对路径；公开仓库里已跟踪的 `.claude/skills/` 目录仍应保留。

## 1. 在项目目录外创建临时目录

在仓库外新建一个临时工作区，再从公开分支匿名 clone：

```powershell
$tmp = Join-Path $env:TEMP ("xhs-clean-accept-" + (Get-Date -Format yyyyMMdd-HHmmss))
New-Item -ItemType Directory -Path $tmp | Out-Null
Set-Location $tmp
git -c credential.helper= -c core.askpass= clone --branch public/main --single-branch https://github.com/Endercloud001/xiaohongshu-workflow.git xiaohongshu-clean
Set-Location (Join-Path $tmp 'xiaohongshu-clean')
```

clone 完后，先确认没有把本机私有目录带进来：

```powershell
git status --short --branch
@(
  '01-账号/账号档案.md',
  '05-验收/已发档案.jsonl',
  '.redbook',
  'node_modules',
  '.cache'
) | ForEach-Object {
  if (Test-Path $_) { throw "unexpected copied path: $_" }
}
```

## 2. 安装并跑完基础验收

依次执行：

```powershell
npm ci
npm run check:config
npm run smoke
npm test
npm run verify -- 06-产出/00000000-verify-fixture
```

期望结果：

- 上述命令全部退出码为 `0`
- `npm run smoke` 会先跑 `render.mjs`，再跑 `verify.mjs`
- `npm run verify` 只检查 `06-产出/00000000-verify-fixture`

## 3. 不安装可选外部工具

这轮验收不要安装：

- OpenCLI
- redbook
- xiaohongshu-mcp
- 第三方视觉 Skill，例如 `cover-anchor-system`、`xhs-visual-director`、`guizang-social-card-skill`

期望结果：

- `npm run check:config` 只把这些能力记为可选，不因缺失而失败
- `npm run smoke` 和 `npm run verify -- 06-产出/00000000-verify-fixture` 仍可正常通过
- 模板渲染、夹具验收和硬校验继续只依赖本地确定性文件

## 4. 公开前审计

执行本地审计：

```powershell
git status --short --branch
git ls-files
git branch -a
git tag -l
git log --all --name-only --format=
npm run audit:security
```

再人工确认这些点：

- `git ls-files` 里没有真实账号档案、真实归档、Cookie、Token、个人路径或可执行二进制
- `git log --all --name-only --format=` 没有把私有资料留在历史里
- `npm run audit:security` 没有报出秘密、私钥、可执行写调用、禁入路径、图片素材或 Markdown 链接问题
- GitHub 上的 CI workflow 只包含 `checkout`、`setup-node`、`npm ci`、`check:config`、`smoke`、`test` 和 `verify`
- GitHub 的 Actions secrets 为空，或只保留仓库确实需要的公开说明里已列出的项
- 仓库分支和 tag 只保留公开候选需要的引用
